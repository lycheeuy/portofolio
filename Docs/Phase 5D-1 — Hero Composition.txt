**Status:** Complete and verified

**Depends on:** Phase 5A (Foundation), 5B (Design System), 5C (Page Shell)

## Objective

Design and implement the Hero — the first major visual section of the
portfolio. Scope is composition only: the Lanyard is not installed or
implemented here (that is Phase 5D-2). An intentional visual zone is reserved
for it.

Design direction preserved: **EDITORIAL × ENGINEERING × PERSONAL**.

## Typography hierarchy

| Role | Font | Token |
|---|---|---|
| Name (dominant) | Fraunces | `--text-hero` (56 → 100px), semibold, tight tracking |
| Full name, index, metadata | JetBrains Mono | `--text-meta`, uppercase where labelled |
| Positioning, CTA | DM Sans | `--text-body-lg` / `--text-body` |

Not every element is oversized — only the name carries display scale. The
three-font system is legible at a glance.

---

## Layout decisions

- **Index opener.** `00` + hairline rule + `FRESH GRADUATE` sets an editorial,
  archive-like tone before the name.
- **Metadata as text, not badges.** Focus areas are an inline mono list — no
  rounded pills, no chips.
- **CTA as text links.** `View work →` / `Read research →` use real anchors
  (`#work`, `#research`) with a subtle arrow nudge on hover. No filled buttons.
- **Bottom border** closes the section and separates it from what follows.

---

## Lanyard reserved area

The right 4-column zone is compositionally intentional without containing a
placeholder graphic:

- A thin vertical rule descends from the top (a suggested hanging point).
- A small terracotta dot marks where the credential will attach.
- Marked `data-lanyard-slot` and `aria-hidden="true"`.
- Hidden below `lg` (`hidden lg:flex`) — mobile position is decided in 5D-2.

It reads as a considered empty space, not an empty gray card.

---

## Responsive behavior

| Breakpoint | Behavior |
|---|---|
| Desktop (≥ 1024px) | Asymmetric 12-column grid; visual zone visible |
| Mobile / tablet | Single-column stack; hierarchy preserved; visual zone hidden |

Mobile is a genuine recomposition, not shrunken desktop type — the clamp-based
tokens scale the name down naturally.

---

## Accessibility

- Semantic `<section aria-labelledby="hero-name">` with a single `<h1>`.
- Focus areas are a real `<ul>` with `aria-label`.
- CTAs are real `<a>` links with visible terracotta focus rings.
- Decorative elements (rule, dot, arrows) are `aria-hidden`.
- No meaning conveyed by color alone.

## Implementation note

During implementation, long Tailwind class strings were extracted to named
constants (`ctaLink`, `ctaArrow`, `metaLabel`) and multi-line JSX attributes
were avoided. This keeps the JSX robust when edited and prevents parser issues
from very long inline `className` values.
